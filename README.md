Entry for [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/c/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68): a program that writes exactly one line — a superpower that is 100% useless — to `entry.txt`. Run it with `node main.ts` (Node 22+, no dependencies); it validates the line (1–200 code points, single line) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
